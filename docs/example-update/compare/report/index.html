How to read this

  • CHANGED — the update moved this metric's window distribution beyond the calibrated line. Whether that is acceptable is a claim decision, not a statistic: check the vs-reference columns.
  • NOT_SEPARATED — no detectable difference at this line with this many windows. Not a claim of equality.
  • INSUFFICIENT — fewer than 5 usable windows on a side.

Caveats

  • the A-vs-B null is a permutation over windows, valid for exchangeable window sets; windows cut from one long simulated path share that path, so within-path long memory makes it slightly liberal (second-order at 1000-day windows for GARCH-class memory)
  • NOT_SEPARATED means no detectable difference at the alpha=0.01 line with this many windows — it is not a claim of equality
  • verdicts are per-metric; nothing aggregates them
