1 · Claim under evaluation

descriptive-market-dynamics — Simulated daily returns reproduce the descriptive dynamics of major equity-index daily returns: heavy-tailed marginals, power-law tail weight, volatility clustering and its persistence, sign-to-volatility asymmetry (leverage), near-unit variance ratios, and empirically small drift.
Use case: Descriptive realism of an unconditional daily return stream — e.g. synthetic training data, method demonstrations, stress-scenario texture. NOT forecasting, NOT derivative pricing, NOT policy counterfactuals.

This report answers only: what evidence supports or contradicts using this simulation for this claim. It does not decide whether the model is “true”, and no aggregate score exists.

4 · Critical findings

Excess kurtosis diverges from the empirical reference HIGH DIVERGES_EXCESS_KURTOSIS

Observation. Across 15 non-overlapping simulated windows vs 124 reference windows, KS=0.871.
Interpretation. The simulated distribution of 'Excess kurtosis' is separated from the empirical reference (KS=0.87, adjusted p=0.003998 at the calibrated line). Note this metric also fails to separate the reference from block_bootstrap, garch_t; treat its pass/fail as one dimension of evidence, not a verdict.
Impact on claim. Weakens support for claim 'descriptive-market-dynamics' on the dimension 'marginal_distribution'. Other dimensions are unaffected by this finding.
Evidence: excess_kurtosis::vs-reference · observations.parquet · artifacts/baseline_context.json
Questions for the author.
  • Did we extract the model output correctly (frequency, units, log vs simple returns)?
  • Is matching the empirical distribution of 'Excess kurtosis' within the intended use of the model?
